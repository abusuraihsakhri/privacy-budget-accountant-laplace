Privacy model and limitations

Count sensitivity is 1 under add/remove-one adjacency. For a mean of n bounded values under fixed-size replace-one adjacency, sensitivity is (upper − lower) / n. Each release uses Laplace noise with scale = sensitivity / ε, and releases compose additively within this tab.

Important: This interface perturbs a query result supplied by you; it does not validate the underlying dataset, population bounds, adjacency assumptions, or participation. Its memory-only budget cannot enforce privacy across tabs, users, sessions, or past releases. Do not use it as a production release gate or as evidence of HIPAA/GDPR compliance.
